# Website Restructuring with Amazon Q

This document outlines the changes made to the website structure using Amazon Q.

## Original Structure
- Single page website with sections for About, Projects, Skills, Testimonials, Blog, and Contact

## New Structure
- Main page (index.html) with bio information only
- Separate pages for different personas:
  - tech.html - Technical professional content
  - personal.html - Personal musings and interests
  - cooking.html - Cooking adventures and recipes
  - contact.html - Coming soon contact page (placeholder)

5. Updated navigation across all pages
